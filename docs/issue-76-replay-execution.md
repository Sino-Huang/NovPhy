# Action-replay execution and operational comparability

The execution plan completes the previously frozen 65-assignment inventory.
It authorizes only fixed-action capture. Model scoring, optimizer work and
fresh access remain disabled. Use the unchanged native live runner with the
tested image-independent one-shot policy and persistent supervised budgets.
A raw complete result cannot override a failed supervisor receipt. An unclean
supervisor exit requires a live-handle/cost audit, not a reset or implicit retry.

The two assigned smoke replays must each have one fixed decision, one accepted
shot, complete native-or-censored observation integrity, all authored entities,
source/seed/role bindings, aligned native/RGB times and causal callbacks. A
censored but intact capture may pass an engineering smoke; it still receives
the separately frozen ranking failure cost and is not a gameplay success.

Before any new replay images, fix the following operational comparability
limits between the reference and candidate:

- Exact scenario, base lineage, generation/engine seeds, training role,
  observation configuration, viewport, world configuration, entity membership,
  lifecycle and body configuration.
- Camera matrices: absolute tolerance 0.000001, no relative tolerance.
- Decoded 640×480 RGB: nonconstant uint8 images; mean absolute difference at
  most one 8-bit intensity unit; at most 1% of pixels differing by more than
  eight intensity units in any channel.
- Every native body, **including birds**: at most 0.01 world-coordinate units
  position difference, 0.01 units/second velocity difference, one degree of
  wrapped rotation difference and one degree/second angular-velocity difference.

These are small, explicit engineering similarity bounds, not proof of identical
hidden physical state or identical future outcomes. RGB alone cannot establish
physical reset equality. The physical check uses the first native captured
sample, while the agent comparison uses the genuine earlier pre-decision
snapshot. Do not confuse those times: require causal ordering and report each
decision-to-capture gap. If action preparation changes the captured initial
body state beyond these bounds, the check fails; do not silently remove birds
or substitute a post-decision input to make it pass.

No criterion depends on task success, model scores, prediction quality or a
hybrid/pure contrast. Retain a failed comparability result and all associated
captures. The remaining 63 assignments cannot run until this exact two-member
smoke is validated. Apply the same checks to each later candidate against its
lineage's original-action reference before admitting paired ranking results.
Reviewable original frames and timing-linked media must accompany publication;
the smoke's frame paths are retained for inspection before continuing.

The original metadata and protocol are not overwritten. Archive the complete
execution source and these numerical criteria before rendering. No #76
advancement or #64/#65 authorization follows from this engineering validation.
