# Keep observed history inside the successor's shared carrier

The canonical big-pig behavior depends on distinct earlier birds, so the #76
successor appends a common 64-value observation/action memory to its 236-value
visual carrier. Both independently fitted dynamics arms receive and predict the
same 300-value carrier; symbolic readouts are decoded from it, never supplied
engine hit counters or a separate oracle history. This requires new checkpoints
and development data, while leaving the older 236-value experiments unchanged.
