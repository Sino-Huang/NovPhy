## Asset/physics mismatch: not a cosmetic missing-file fix

The appearance XML requests `PinkBigPig`. The aligned Unity project/player only
registers `BasicBig`, `BasicMedium` and `BasicSmall` as built-in pigs. Both failed
scenes show birds/slingshot/background but no authored target objects. Their
Unity logs contain `KeyNotFoundException` in `ABGameWorld.DecodeLevel`, followed
by slingshot null-reference errors. This is an infrastructure failure, not a
model failure or a completed novel-physics rollout.

The exact canonical asset exists in the repository's original
`sciencebirdsgames/Linux/9001_Data/resources.assets`. A pinned, read-only
UnityPy1.25.3 audit compares that bundle with the aligned player's bundle:

| `BasicBig` property | Original bundled game | Aligned player |
| --- | --- | --- |
| Behavior script | `DieOnBirdHitCountPig` | `ABPig` |
| Mass | 1.5 | 0.70186746 |
| Gravity scale | 0.5 | 0.47999999 |
| Angular drag | 0.05 | 2.0 |

The original `DieOnBirdHitCountPig` assembly declares
`numberOfBirdShotsToDie`, `allBirdIDs` and `collidedBirdIDs`. Its source component
is absent from the aligned Unity project. Restoring the actual benchmark
requires asset **and behavior/history** compatibility, not renaming/tinting a
normal pig. The canonical normal/PinkBigPig pair also differs in its serialized
collision-detection setting; pure appearance-only equivalence has not been
established.

This is an additional, post-smoke source/asset diagnosis, not a retrospective
change to the frozen parser thresholds. The upstream overview describes the
objects category using changed color, but the concrete serialized implementation
must also be audited. See the [upstream benchmark description](https://github.com/phy-q/NovPhy#2-novelties-in-novphy)
and the [asset reader documentation](https://github.com/K0lb3/UnityPy).

No assets were substituted. In particular, the full original `resources.assets`
was not blindly swapped into the instrumented player: that could change normal
physics and script bindings. All earlier results remain evidence about their
recorded aligned runtime, not newly certified canonical NovPhy physics.
