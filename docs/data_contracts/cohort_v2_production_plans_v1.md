# `cohort_v2_production_plans_v1`

> Historical authority: issue #53 plan v2 supersedes this plan for future
> production execution. This v1 plan and every release derived from it remain
> immutable evidence of the original termination-expectation defect.

Issue #52 publishes two immutable, declared-identity plans for the central-v2
cohort. They are bound to the accepted issue-51 representative pilot and do not
amend the older scoped collection, pilot, or production-parameter artifacts.

The collection plan identity is
`cohort-v2-production-collection-plan-v1:issue-52`. It projects the exact
issue-47 instance-held-out exposure assignments without exposing the sealed
final-evaluation manifest. Each of the four role lineages receives six ordered,
single-shot interventions—one for each central coverage stratum—for 24 planned
attempts. The plan fixes both interface and engine-relative action forms,
geometry-aware and targeted sources, a closed termination vocabulary, one
attempt per intervention, no retries, atomic quarantine, and no quota-fill
resampling.

The production-parameter plan identity is
`cohort-v2-production-parameter-plan-v1:issue-52`. It freezes fixed-step stride
1, a two-fixed-step stability window, a 600-fixed-step post-intervention
ceiling, every numeric input used by the six accepted central labels, and the
accepted replay comparison bounds. Each parameter value names its unit and a
derivation-evidence record containing accepted non-final source record IDs,
analysis method, observed range or uncertainty, decision rule, rationale, and
plan version.

Quotas are prospective. They are separately declared by benchmark condition,
exposure role, instance-held-out partition, scenario template and level
instance, intervention source, central stratum, supported termination class,
and required capability. Realized outcomes cannot alter attempt order, trigger
replacement attempts, or mutate either plan.

Bounded-negative/SPSG evidence and material and physical-regime labels retain
named-secondary dispositions. Damage, gravity-shift generalization, and
template-held-out evaluation remain out of scope. `cascade-active`, `collapsed`,
`pigs-cleared`, and `illegal_contact` remain excluded and are not emitted as
false. Benchmark-agent actions remain optional and unavailable because the
accepted pilot contains no provenanced benchmark-agent action.

The non-launching check is:

```sh
python -u -m scripts.build_issue_52_evidence --dry-run
```

The progress-reporting publication or exact revalidation command is:

```sh
python -u -m scripts.build_issue_52_evidence \
  --output data/runtime_evidence/issue-52
```

Both commands print each validation and publication phase immediately. The
second command refuses different bytes at an existing immutable publication
and validates exact bundle membership and source-bound re-derivation.
