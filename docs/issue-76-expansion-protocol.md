# #76 broader-coverage implementation: compatibility stage v1

This is a new, prospective development protocol following the user's explicit
request to implement the ten conditional checklist items. It does not amend the
completed diagnostic, reverse #75, or authorize #64/#65. The first stage answers
whether the existing shared deployed interface can represent and observe the
proposed broader conditions. Compatibility is not power or candidate superiority.

## Symmetric engineering and cost decision, before implementation

Implement condition-aware scenario materialization and one-level runtime
packaging in new files, preserving the frozen #62–#76 implementations. Use the
canonical generator and workbook-mapped normal/novel coordinate constraints.
Runtime XML must reside under its actual novelty level/type, not be relabeled
as normal type2. Use the existing graphics-enabled aligned observation player.

Both model arms retain the same #70-v6 CNN, 18 authored slots, 236-value carrier,
adjacent-frame motion semantics, 12-action bounds, and #74 checkpoints/seeds
20260908/20260909/20260910. Architecture changes, new slots, new oracle hints and
training updates are **zero for both arms** in this compatibility stage. All
perception measurements use the shared parser; engine state is evaluation-only.

Budget this implementation at the previously proposed eight engineering hours.
The full compatibility capture allowance is eight attempts, 30 minutes cumulative
active collection wall, 3GiB aggregate process RSS and 2GiB captured/derived data.
Use one isolated worker at a time, with fresh private ports, runtime directory
and virtual display. Player-runtime copies are reusable infrastructure, recorded
separately from the 2GiB captured-data allowance. A per-attempt watchdog is 240s;
capture is capped at 600 fixed-step offsets. Watchdog overshoot is recorded as a
technical failure with partial files retained, never silently truncated.

If the shared parser/carrier fails, do not resize or refit one arm. The next
representation/training amendment must specify one common observation/slot
contract, shared parser data/updates, paired pure/hybrid predictor data and
updates, controller supervision, held-out roles, and an explicit collection/
GPU-hour/storage budget. That new candidate cannot be declared viable from this
eight-attempt smoke. No uncosted refit or additional repair loop is hidden here.

## Measurements and compatibility decisions

Retain request-71 physics data, synchronized agent PNGs, observation transform/
timing metadata, engine/game/physics ports, actual environment seed, all failures,
and review WebMs/manifests. Preserve source timing: a stride1 frame sequence is
encoded at the reciprocal recorded fixed delta, not an arbitrary playback rate.

Check generated and runtime authored IDs against all 18 slots without dropping
entities. At initial, elapsed150, elapsed225 and terminal observations, evaluate
the frozen parser at B=1. Use actual predecessor frames for any carrier motion;
no future observations initialize the model. Earlier terminal images are labeled
with their actual offset and are not relabeled requested225 predictions.

Report task-slot presence (pig/block) probability error and threshold0.5
classification, true/predicted pig and block counts, and normalized center error
on available active entities. Reuse #70's projection and lifecycle semantics.
These are parser compatibility measurements, not physical-validity or dynamics
scores. The shared parser is assessed once, not counted as independent evidence
for each model seed.

Initial compatibility criteria, fixed before new images: no missing authored
slots; valid synchronized nonconstant RGB; finite 236-value carrier; no capture
or budget failures; initial pig-count absolute error <=0.25, initial block-count
absolute error <=0.5, and initial mean center absolute error <=0.10 on active
task slots. Report every individual criterion and every attempt, including
failures and conditions that miss these thresholds. These thresholds are an
engineering screen, not a practical-effect margin for a scientific experiment.

No unsupported physical-force/event observability claim is inferred from a
passing appearance smoke. Full-shot/multi-shot observation needs, new force
semantics and unseen novelty generalization remain separate capability questions.

## Execution, resume and stop

`--dry-run` checks metadata and code paths without new rendered data or writes.
`--prepare` freezes this stage and materializes its exact eight development
instances before gameplay. `--smoke-test` executes only the first normal/novel
pair as the bounded real wiring check, retaining those as the first two scheduled
attempts. `--run-smoke` resumes the full eight-attempt inventory with foreground
stage/progress/elapsed/ETA logs. A completed attempt is not rerun. An interrupted
attempt is a retained technical failure, not silently retried or replaced.
`--publish` and `--validate` include incomplete/failure/budget-stop dispositions.
No positive full-smoke decision is available from only the first two attempts.

## Remaining fresh-test and archival prerequisites

This stage cannot freeze a *viable* fresh candidate: the current #75 candidate
failed. Its outcome can inform a prospectively costed shared repair, not rescue
the old gate. Fresh population/counts/power, practical margins, multiplicity,
paired gameplay success/shots, full compute constraints, once-only generation
and novel-effect analysis must be attached to an actually eligible system and
its exact new protocol before access. Do not provide an apparently runnable
fresh command that bypasses these missing scientific prerequisites.

Commit/push and the large-asset archive destination are being requested from
the user separately. No remote write or local-snapshot-as-archive assertion is
implied by this protocol. Before fresh access, the code, checkpoints and retained
repair/failed-attempt artifacts must have a verified archive receipt, not merely
an output-directory flag. #64/#65 remain blocked without the exact supported
advancement disposition and all declared gates.
