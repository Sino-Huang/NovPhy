# Balanced full-rollout event-ranking engineering screen

This prospective screen uses the already exposed 2,600-row event cohort only
for engineering. Its old training/calibration/model-selection roles remain
unchanged, but the old model-selection outcome is not new readiness evidence.
No result here opens fresh evaluation or passes the advancement gate.

Bind the completed balanced-native v2 surface and its norm-recovery receipt.
Keep all three paired seeds, frozen balanced parsers and observed-history
encoders, both capacity-matched dynamics arms, and the original event inputs,
causal reference-image alignment, unavailable rows, actions, and stop targets.
No dynamics optimizer runs in this stage.

For every action and permitted pair, roll only predicted carriers through the
full 11,250-native-step window. Retain fixed endpoints plus predicted states at
elapsed steps 0, 3,750, 7,500, and 10,500. All three horizons divide these points.
A non-finite trajectory is a retained hard failure, not a dropped candidate.

Fit the same 256-hidden-unit event readout separately for both arms and all
seeds, 4,500 AdamW updates at lr 0.001. Each update uses one assigned training
lineage and one fixed-pair endpoint, with weighted four-stop-kind classification
and the existing within-lineage clear-ranking loss. Both arms have identical
lineage update exposure and readout capacity; invalid captures do not acquire
invented targets.

For each valid training record, choose a fixed pair by observed-class readout
loss plus 0.0001 times its full-rollout linear-MAC cost normalized by the native
reference-transition cost. This coefficient is fixed before scoring. Train the
existing matched selector for 2,000 updates at lr 0.001, batch 128, using the
chosen pair's four predicted states and their true remaining native steps.
Both arms draw the same training records and elapsed checkpoints. No
calibration/model-selection outcome enters either optimizer.

At deployment, reselect mode and horizon on the current predicted carrier at
every transition. Mask only horizons that exceed the remaining window, stop at
exactly 11,250 steps, and score the resulting adaptive endpoint with the same
readout. Average probabilities across the three paired seeds. Record every
transition choice and actual selector/model/readout linear MAC. Non-degeneracy
is measured over all adaptive choices in admissible engineering groups, not
only the initial selector choice.

Calibration selects each arm's strongest fixed pair, then selects primary pure
between its adaptive and fixed policies. It also selects the no-model training
family prior versus original action. The old model-selection role is then
scored once as an exposed engineering inventory. The screen asks for at least
one useful hybrid-adaptive clear hit and one more hit than primary pure, the
same hybrid's selected fixed policy, and the selected no-model baseline; second
mode and horizon fractions must each reach 5%. Hybrid adaptive linear MAC must
be at most 1.10 times the actual calibration-selected primary pure policy,
including fixed-policy cost if fixed is selected.

Feature and scoring jobs each have 3,600 active seconds, fitting jobs 1,800,
with the existing 12 GiB RSS and 8 GiB allocated CUDA limits. Retain all jobs,
failures, counters, and source bindings. A completed positive screen means
only that a new disjoint development readiness cohort is warranted. Such a
cohort must be frozen and collected before readiness or fresh-access claims.
