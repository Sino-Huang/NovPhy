# Independent implementation review — Milestone 0a

## Blocking

- **CRITICAL — the advertised strict reader does not fail closed on same-type record reordering.** `read_macro_labels` promises to “**Strictly parse a macro-label sidecar, failing closed on any contract drift**” (`scripts/physics_macro_labels.py:1148-1149`), but after parsing it checks only duplicate frame identities (`:1216-1218`) and absorbing reversion (`:1219-1224`). It never requires event intervals to be in canonical `(start_fixed_step, interval_type)` order, nor frame labels to be in accepted state/sequence order. Thus swapping two non-absorbing frame-label lines (for example, fixed steps 11 and 12 in the canonical fixture) leaves the header counts and identities unique and is returned successfully by this supposedly strict reader. This directly violates the governing hard-reject requirement for “**wrong record order/count, noncanonical order/bytes**” (`.claude/project-docs/plans/milestone-0a-macro-outcome-labels.md:279-283`) and the requested invariant that record order fails closed. `validate_macro_labels` happens to protect the current supervision path by byte-comparing a rederivation (`scripts/physics_macro_labels.py:1238-1254`), but that does not make the independently exported strict reader conformant. Enforce canonical interval/frame order in `read_macro_labels` (and add mutations that swap same-type interval and frame records); do not rely on every future caller to remember the separate validator.

- **CRITICAL — the fixture-only CLI still has an unrestricted real-cohort write mode.** `_label_path` explicitly returns “**`shot / MACRO_LABEL_SIDECAR`**” when no output directory is supplied (`scripts/derive_physics_macro_labels.py:69-74`), and `main` then calls “**`label_path = write_macro_labels(shot)`**” (`:110-115`). The only guard rejects paths containing the *current active cohort's directory name* (`:50-66`); any valid non-active cohort path is writable, and `--output-dir` is likewise unrestricted. This is incompatible with the fixture-only boundary: “**Fixture implementation writes only to temporary test directories. It must not write labels into a real cohort**” (`milestone-0a-macro-outcome-labels.md:261-268`) and “**writing labels into a real cohort**” is expressly forbidden (`:376-383`). The evidence proves the particular commands used `/tmp`; it does not turn this broadly destructive interface into a fixture-only implementation. Remove in-shot writes and constrain both target and destination to the committed fixtures plus an explicitly temporary output root, or fail closed on every non-fixture destination. Add a regression showing a valid physics tree outside the active-cohort-name heuristic is refused rather than written.
