## Authoritative gap list

The following remain unavailable for the broader issue #2 research use and therefore block closure:

1. A capability-complete representative pilot and production coverage: broader prospective target strata, bounded negative evidence, representative physical regimes, deterministic replay, fixed-step stride authority, access-separated canonical and agent observations, broader termination coverage, and representative scenario/template coverage.
2. Empirical exposure isolation: real cross-role instance-held-out evidence, template identities and template-held-out evidence, and a release-bound role-separated final-evaluation workflow/access record.
3. Accepted physical-regime labels.
4. Accepted physical-violation labels for excess penetration and unsupported stationary/floating body; `illegal_contact` additionally lacks an accepted legal-contact ontology.
5. Accepted material identity and damage semantics. Raw `life` remains only an uninterpreted engine fact.
6. Accepted representative semantics for `cascade-active`, `collapsed`, and `pigs-cleared`. Their explicit rejected/out-of-scope disposition is scientifically useful but does not satisfy a required macro capability.
7. Full downstream ingestion proof for the missing derivations, access-separated observations, template-held-out restrictions, and actual final-evaluation access boundary.

Legacy continuous-only artifacts, RGB-only evidence, fixture-only macro/label tests, command success, and smoke-only evidence were excluded as sufficient closure evidence. They may establish software behavior, but issue #18 Section 16 explicitly forbids using them to fill the gaps above.
