Envelope

- Inner header: magic SBPV, version uint8 1, flags uint8, failure code uint16,
  payload length uint32, all integer fields network order.
- Success flags/code are zero. Success payload is three uint32 lengths followed
  by exactly one PNG, one UTF-8 state JSON object, and one UTF-8 event JSON list.
- Failure flag is 1 and payload is one uint32 message length plus UTF-8 message.
- Python bounds are 64 MiB envelope, 32 MiB PNG, and 16 MiB per JSON record.
- Bad magic/version/flags/length/JSON/frame equality/PNG/overflow disconnects
  before another request can be read, preventing stream desynchronization.
- Returned Python records are frozen dataclasses with recursively immutable JSON.
