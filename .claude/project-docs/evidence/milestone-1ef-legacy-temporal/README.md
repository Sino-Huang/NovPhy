# Milestone 1e/1f Legacy Temporal Evidence

This directory contains the Todo 8 evidence for the continuous-only legacy
temporal projection. The authoritative run is `runs/m1ef-primary`; the second
fresh CUDA run is `runs/m1ef-repro`. Checkpoints, run directories, and score
shards remain ignored and are not committed here.

The dev catalog was rebuilt in a fresh process: 463 episodes, 5,556 shots,
562,515 frames, 1,137 `missing_artifact` rejections, digest
`8265809a528e41eaae646cb1cae9d577d7f34fd99b85b859bb14f07a479c6beb`.

Both runs used seed `20260807`, 3,600 steps, batch 64, learning rate `3e-4`,
weight decay `0.05`, warmup `0`, grad clip `1.0`, EMA base `0.996`, CUDA, and
the approved `delta={1,5,15}`, `continuous` grid. Fresh score validation passed
for both runs at 556,959 states and 1,670,877 scores. The primary frontier was
generated by the real CLI with 1,000 bootstrap replicates and has verdict
`not_supported`.

The reproducibility gate did not pass: experiment identity and update counts
match, but aggregate metrics exceed `rtol <= 1e-2` and best-pair agreement is
`0.9695291753971118`, below `0.99`. See
`reproducibility-comparison.json` and `temporal-only-claim-boundary.md`.

`micro` and `macro` are explicitly unavailable with reason
`symbolic_supervision_unavailable`; no symbolic or physical metric is
fabricated. The protected dataset root and staged Unity player are unchanged;
see `protected-roots-before-after.txt`.
