# Unity 2019.4.41f2 headless runtime audit notes

- Unity 2019.4 Editor batch probes should use `-batchmode -quit -logFile <absolute-path>`; Unity documents batch failures as return code 1 and says `-executeMethod` can return a non-zero code through an exception or `EditorApplication.Exit`.
- `-nographics` prevents graphics-device initialization in batch mode. It is the supported no-GPU probe switch. Always supply `-logFile`, because current Unity documentation notes that output logging is disabled by default in this mode.
- The 2019.4 command-line references list `-disable-gpu-skinning`, not `-disable-gpu`; the former disables GPU skinning only and is not a general graphics disable. `-force-gfx-st` is documented by the 2019.4 `RenderingThreadingMode.SingleThreaded` API as an internal/debug mode for a Development build on some platforms, not as a general headless switch. `-force-gfx-direct` is the documented single-threaded rendering option for the 2019.4 Standalone Player reference.
- `DISPLAY` is an X11 connection name. Unset it for a `-nographics` probe to test that no X connection is needed. For a graphics-path probe, set it only to a live, authorized X server; `DISPLAY=:99` alone does not create a server. `XAUTHORITY` may be required by X access control.
- On Linux, `LD_LIBRARY_PATH` is consulted by the dynamic loader before RUNPATH/cache/default paths. Prepending an exact, trusted plugin directory is safer than replacing the path or adding `.`; verify dependencies with `ldd`/`readelf` before launching.
- Classify process results separately: normal Unity exit code, timeout (GNU `timeout` returns 124; forced KILL commonly returns 137), and signal termination. POSIX does not make the shell's `128+signal` convention a reliable exact status; native supervisors should inspect `waitpid` with `WIFEXITED`/`WEXITSTATUS` and `WIFSIGNALED`/`WTERMSIG`.
- For bounded cleanup, isolate each run in a unique temporary root and process session, send TERM first, then KILL only after a short grace period, wait/reap the child, verify no Unity/Xvfb descendants remain, and remove only that run root. Never run the Editor against the user's only project copy when claiming source read-only: project opening/import can write Library, logs, package state, or user config.

Primary sources: Unity 2019.4 EditorCommandLineArguments, PlayerCommandLineArguments, LogFiles, CLIBatchmodeCoroutines, RenderingThreadingMode.SingleThreaded, EditorApplication.Exit, GraphicsDeviceType.Null; X.Org X(7); Linux `ld.so(8)`, `waitpid(2)`, GNU Coreutils `timeout`, and util-linux `setsid`.
