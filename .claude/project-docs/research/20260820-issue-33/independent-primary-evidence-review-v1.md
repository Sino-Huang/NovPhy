## Decision rule

- **PASS** means the complete condition is demonstrated by current primary evidence.
- **PARTIAL** means primary evidence demonstrates a proper subset, while one or more required elements remain rejected, unavailable, or unexercised.
- **FAIL** means a primary artifact explicitly records that the condition's essential gate is not met.

An explicit unavailable or rejected disposition is useful fail-closed accounting, but it is not accepted capability evidence. No filename, image content, fixture, command exit status, or diagnostic value is used to infer a missing fact. The accepted pilot and cohort artifacts were inspected in place and were not modified.
