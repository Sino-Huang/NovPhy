\subsection{\texorpdfstring{\rev{Validation commands and last observed status}}{Validation commands and last observed status}}

Activate the environment before running any command: \texttt{conda activate novphy \&\& source env.sh}, where \texttt{env.sh} puts the repository root on \texttt{PYTHONPATH}. All commands below run from the NovPhy repository root. The recorded source revisions are \texttt{env@254720f} for the \#74 and \#77 records and commits \texttt{0a0dd73} plus \texttt{ac2a4e1}, \texttt{8399f57}, and \texttt{9e369c4} for the \#79 line. Each \texttt{-{}-validate} mode recomputes the published tables from the retained artifacts and must exit 0. The validators never retrain a model. The external-baseline validator was verified on both cpu and cuda.

\begin{revblock}
In the recorded reproduction check dated 2026-10-23, 23 of 32 commands exited successfully; nine stopped at frozen-input integrity checks before recomputation. The reproduction appendix reports each artifact's last observed validation status and date. No experiment validator was rerun for this manuscript revision.

Table~\ref{tab:app:repro} gives, for each artifact family, its root, its command and that status. The nine stops have two causes. Pinned plans or inputs carry absolute paths of an earlier checkout location or uncommitted path rewrites from a server migration, and four of the 36 capture sources pinned by the \#77 N1 campaign were edited after its freeze. Each stop happens before any recomputation, so it neither confirms nor contradicts a published table. Later program-specific validations, those of the \#127 program and its children, are listed separately with their own result and date. Commands that were not part of the 2026-10-23 check are marked as such.

In the 2026-10-23 check it stopped at its freeze check because two frozen data paths point to an earlier checkout location.}

The small-artifact subset of \rev{the submitted-checkpoint roots in Table~\ref{tab:app:repro} (\#74, \#77, \#79, \#84, \#92)} (plans, summaries, comparisons, findings, records, receipts, and ledgers) is version-controlled through commit \texttt{2b4d897}, and the \#96 root through \texttt{0e7f921c}.
